# Flight Radar Frontend

React + TypeScript + Vite frontend for the Flight Radar app. It renders the radar view, flight table, route and trail overlays, and the settings and info dialogs.

## Scripts

- `npm run dev` starts the local Vite dev server.
- `npm run build` creates a production build.
- `npm run lint` runs ESLint.
- `npm run test` runs the Vitest test suite.

## Notes

- Static map assets are served from `public/`.
- The UI expects flight data from the backend API in the same repository.
