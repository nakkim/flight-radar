# Flight Radar

Monorepo for a small flight radar application with a React frontend and a Node.js backend API.

## Projects

- `frontend/` contains the radar UI built with React, TypeScript, and Vite.
- `backend/` contains the API that fetches and processes nearby flight data.

## Root Scripts

- `npm run install-all` installs dependencies for both projects.
- `npm run build` installs dependencies and builds the frontend.

See `frontend/README.md` and `backend/README.md` for project-specific details.
